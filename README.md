# Flurell.pk – JavaScript Assignment

## Project Overview
This project adds interactive functionality to the Flurell.pk jewelry website using JavaScript. It improves the user experience through dynamic features and interactive elements.

## Technologies Used
- JavaScript
- HTML5
- CSS3

## Features
- Form validation
- Product selection
- Dynamic price calculation
- Discount checking
- Category filtering
- Dark mode functionality
- User feedback and interactive elements

## How to Use
1. Download or clone this repository.
2. Place `script.js` in the same folder as the corresponding HTML file.
3. Link the JavaScript file before the closing body tag using `<script src="script.js"></script>`.
4. Open the HTML file in a browser.
